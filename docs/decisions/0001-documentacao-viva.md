# ADR 0001: documentação viva

- Status: aceita
- Data: 2026-09-28

## Contexto
O projeto precisa preservar decisões de produto, arquitetura, segurança e operação.

## Decisão
Manter documentação versionada em `docs/`, atualizada junto ao código e com TODOs explícitos.

## Consequências
Há custo de manutenção, mas decisões ficam rastreáveis e revisáveis.
