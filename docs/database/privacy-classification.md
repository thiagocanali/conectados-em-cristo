# Classificação de privacidade

## Objetivo
Classificar dados pelo risco e definir minimização.

## Escopo
Dados de identidade, contato, perfil, preferências, mensagens, denúncias e logs.

## Princípios
Coletar o mínimo necessário, limitar acesso, definir retenção e permitir direitos aplicáveis.
