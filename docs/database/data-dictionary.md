# Dicionário de dados

## Objetivo
Definir o vocabulário funcional dos dados do produto sem antecipar o esquema físico.

## Escopo
Contas, perfis, preferências, compatibilidade, interações, moderação, consentimentos e auditoria.

## Regras
- Cada campo deverá ter finalidade, classificação de privacidade, retenção e responsável definidos antes da implementação.
- Dados sensíveis não devem ser expostos por padrão.
